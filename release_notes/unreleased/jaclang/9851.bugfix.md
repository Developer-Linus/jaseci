- **Fix: `jac scale ... --dry-run` no longer rejects a valid KEDA scale-to-zero service**: the plan check refused every `hpa.min` below one, so a service with `autoscaler_engine = "keda"`, `hpa.min = 0` and a real event trigger failed with `HPA min=0; must be >= 1`. It now flags `hpa.min` below one only when the workload could not wake from zero: the plain HPA engine, or KEDA with no event trigger (cpu and memory targets cannot fire with no pods running). The error names the fix that applies to the engine in use, and a fleet-wide `min_replicas` of zero is now checked the same way as a per-service `hpa.min`.
