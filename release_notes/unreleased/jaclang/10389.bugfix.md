- **Observability no longer lifts the Pod Security sandbox it does not need**: Turning on monitoring, logs or tracing used to relabel the app's namespace to Pod Security `enforce=privileged` for good, including the `default` namespace. Now only node-exporter (Kubernetes metrics) and log collection, the two components that mount host paths, request it. Tracing alone keeps the namespace at `baseline`. A `privileged` level jac-scale set is restored to `baseline` on the next deploy once nothing needs host access, and `default` is never relabelled.
